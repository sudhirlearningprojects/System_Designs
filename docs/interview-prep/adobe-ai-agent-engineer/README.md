# Adobe Agentic Outcome Engineer — Interview Preparation

## Role Summary

**Position**: Agentic Outcome Engineer (Full-Stack Development)
**Company**: Adobe (San Jose, CA)
**Level**: 5-7 years experience
**Function**: Software Engineering → Full-Stack Development

---

## Key Differentiators to Highlight in Interview

1. **Full-stack + AI**: You can build the entire product, not just the AI part
2. **Observability expertise**: You know how to monitor AI systems in production (New Relic, Splunk, RUM)
3. **Outcome-oriented**: You define metrics and run experiments, not just ship features
4. **Customer empathy**: You use support data and analytics to improve experience
5. **Production mindset**: You think about operations, middleware, web servers — not just prototypes

## 90-Day Plan (Have This Ready)

```
DAYS 1-30: LEARN & UNDERSTAND
├── Understand Adobe's existing agent systems and architecture
├── Map the observability stack (New Relic, Splunk, RUM setup)
├── Meet stakeholders (product, design, support, engineering)
├── Identify top 3 customer pain points from support data
├── Set up local dev environment, deploy first change
└── Deliverable: Architecture doc + opportunity assessment

DAYS 31-60: BUILD & SHIP
├── Ship first agent improvement (quick win based on data)
├── Set up metrics dashboard (task completion, CSAT, latency)
├── Implement/improve observability for agent interactions
├── Design first A/B experiment
├── Establish evaluation framework for agent quality
└── Deliverable: First measurable improvement live in production

DAYS 61-90: MEASURE & SCALE
├── Analyze A/B experiment results
├── Propose roadmap for next quarter based on data
├── Identify platform opportunities (reusable components)
├── Document patterns and best practices for team
├── Present results to stakeholders
└── Deliverable: Data-backed roadmap + team knowledge sharing
```
